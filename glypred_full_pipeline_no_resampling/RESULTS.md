# 论文完整流程（不重采样）运行结果

## 运行设置

- 设备：NVIDIA GPU（CUDA）
- 数据：筛除 2 条非 31 位的负样本后，正样本 3,573 条、负样本 3,571 条
- 重采样：关闭
- 评估：分层五折交叉验证；每一外层训练折中独立完成 LightGBM 特征筛选、标准化和早停验证
- 特征：AAC（20）、PWAA（21）、EBGW（15）、二肽 KMER（441）、DR（1,344），融合前共 1,841 维
- 特征选择：LightGBM `split` 重要性大于 2；每折保留 435--464 个特征，平均 454.8 个
- 分类器：BiLSTM + LayerNorm + 多头注意力 + GELU + Dropout + 残差；Adam，学习率 0.01，L2=0.005，batch size=64，早停 patience=8

## 五折汇总

| 指标 | 均值 | 标准差 |
| --- | ---: | ---: |
| SN | 0.6000 | 0.5477 |
| ACC | 0.5000 | 0.00035 |
| SP | 0.4000 | 0.5477 |

逐折指标见 `results/full_pipeline_5fold.csv`；各类特征被选中的数量见 `results/selected_feature_families.csv`。

## 结果解读

该直接迁移版本未获得有效分类能力：5 个测试折中，模型分别几乎将全部样本预测为正类（第 1、2、4 折）或负类（第 3、5 折），故 ACC 约为随机水平、MCC 为 0。验证损失也都接近二元随机猜测对应的 0.693。

这不是数据泄漏导致的高分，而是训练不稳定/类别塌缩的明确信号，因此不能将其表述为实验改进。相较于当前 One-hot + 逻辑回归基线（ACC 0.5601、MCC 0.1201），该完整论文流程在本数据与本评估条件下表现更差。

## 与论文的边界

实现保留了论文的五类融合特征、LightGBM 特征选择和注意力 BiLSTM 的主要结构与给定优化器超参数；但当前数据近似均衡且只提供训练集，所以按要求关闭了论文中为原始不均衡训练集设计的 CCU 重采样，并以五折交叉验证替代论文的独立测试集。上述差异意味着这里是“论文路线在本数据上的可复现实验”，而不是可直接对齐论文公布指标的逐字复现。

## 下一步建议

若目标是实际提升性能，应在每个外层训练折内调低学习率、适当减小正则/Dropout，并以验证集 AUC 或 MCC 选择超参数；这将形成一个单独的“论文路线调优版”，不应与本次严格超参数迁移的结果混淆。
