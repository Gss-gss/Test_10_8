# Glypred 五特征融合逻辑回归基线

本目录是对现有 One-hot + 逻辑回归实验的特征层改进：保留 31 位窗口、中心 K 检查、逻辑回归、随机种子和分层五折交叉验证；仅将特征替换为 Glypred 论文中的五类融合特征。

## 特征

特征按以下顺序连接：

1. **AAC**：20 维天然氨基酸组成。
2. **PWAA**：21 维位置加权氨基酸组成。
3. **EBGW**：15 维基于分组权重的理化性质编码，分段数 J=5。
4. **KMER**：21 符号字母表上的二肽频率，k=2，441 维。
5. **DR**：氨基酸组成加距离为 1、2、3 的残基对计数，1,344 维。

总特征维度为 1,841。为匹配论文的符号约定，输入中的 `X` 会映射为人工残基 `O`；当前筛选后的训练数据不含 `X` 或 `O`。

## 运行

在本目录中执行：

```powershell
python .\run_fused_logreg_cv.py
```

脚本默认从上级目录读取 `trainPos.txt` 与 `trainNeg.txt`，只保留长度为 31 且第 16 位为 `K` 的窗口。输出写入 `results/`：

- `feature_audit.json`：样本筛选、特征维度、模型与交叉验证配置。
- `fused_feature_logreg_5fold.csv`：逐折混淆矩阵、SN、ACC、SP、MCC 和 AUC，以及均值与样本标准差。

## 方法边界

本实验是论文五特征融合的**逻辑回归基线**，尚未加入论文后续的 LightGBM 特征选择、CCU 欠采样和 BiLSTM 注意力分类器。当前数据集的正负样本近似平衡，因此不应使用 CCU；CCU 只应在有大量原始负样本的不平衡训练集内使用。

DR 特征采用论文公开预测器所用的 21 符号、`max_dis=3` 和 1,344 维输出布局实现；作者预测器调用 Pse-in-One 生成该特征。本实现将其写为透明、可复现的 Python 版本，避免外部命令依赖。
