# 五特征融合逻辑回归结果

运行命令：

```powershell
python .\glypred_feature_baseline\run_fused_logreg_cv.py
```

数据筛选后保留 3,573 条正样本与 3,571 条负样本；剔除 2 条长度不为 31 的负样本。所有保留窗口的第 16 位均为 K。

| 指标 | 五折平均值 | 样本标准差 |
|---|---:|---:|
| SN | 0.5402 | 0.0163 |
| ACC | 0.5479 | 0.0152 |
| SP | 0.5556 | 0.0164 |
| MCC | 0.0958 | 0.0304 |
| AUC | 0.5725 | 0.0153 |

与先前的 31 位 One-hot + 逻辑回归基线（ACC 0.5601，MCC 0.1201）相比，本次五特征融合在相同分层五折设置下未提升性能。因此，不应把“五特征融合 + 逻辑回归”当作最终改进模型；它应作为下一阶段 LightGBM 特征选择和 BiLSTM 分类器的输入基线。
