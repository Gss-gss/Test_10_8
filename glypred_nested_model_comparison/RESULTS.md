# 融合特征分类器嵌套对比实验结果

## 实验设置

- 数据：过滤两条非 31 位负序列后，正样本 3,573 条、负样本 3,571 条；不使用重采样。
- 特征：AAC、PWAA、EBGW、二肽 KMER、DR 五类特征融合，共 1,841 维。
- 特征选择：在每个内层训练分区和最终外层训练折中，单独训练 LightGBM，以 `split` 重要性大于 2 筛选特征；平均保留 454.8 个特征。
- 验证：外层分层五折给出最终指标；每个外层训练折内使用分层三折，按平均验证 AUC 在 9 个候选设置中选择模型。外层测试折未参与特征选择、标准化、模型选择或参数选择。
- 候选：3 个 LightGBM 设置、3 个 RBF-SVM 设置、3 个 GPU MLP 设置。

## 内层比较结论

各候选的 15 次内层验证平均 AUC 约为：

| 排名 | 模型与设置 | 平均内层 AUC |
| ---: | --- | ---: |
| 1 | LightGBM，learning rate=0.02，num_leaves=15 | 0.6300 |
| 2--3 | 其他 LightGBM 设置 | 约 0.6200 |
| 4 | RBF-SVM，C=0.3 | 0.6000 |
| 5--6 | 其他 RBF-SVM 设置 | 约 0.5900 |
| 7--9 | 三个 MLP 设置 | 约 0.5700--0.5800 |

五个外层折都独立选择了排名第一的 LightGBM 设置，说明该结论在不同训练子集上稳定。

## 外层五折最终结果

| 指标 | 均值 | 标准差 |
| --- | ---: | ---: |
| SN | 0.6154 | 0.0252 |
| ACC | 0.6006 | 0.0176 |
| SP | 0.5858 | 0.0120 |
| MCC | 0.2014 | 0.0353 |
| AUC | 0.6435 | 0.0141 |

逐折明细位于 `results/nested_model_comparison_5fold.csv`；所有内层候选评分位于 `results/inner_candidate_scores.csv`。

## 解读

融合特征更适合树模型或核方法等表格分类器，而不是直接将人为排列的特征向量视作序列交给 BiLSTM。本次结果中，LightGBM 的 AUC 0.6435、MCC 0.2014，高于此前五融合特征 + 逻辑回归（AUC 0.5783、MCC 0.1070）以及 One-hot + 逻辑回归（AUC 未报告、MCC 0.1201）。它也略高于此前调优 One-hot BiLSTM 的 AUC 0.6340、MCC 0.1833。

因此，在当前仅有训练数据、近似均衡且不重采样的条件下，推荐将“融合特征 + LightGBM 特征选择 + LightGBM 分类器”作为当前最佳基线。后续若希望报告更可信的最终泛化能力，应保留独立测试集；若没有独立数据，则继续报告本嵌套五折结果，不再使用其外层测试折调参。
