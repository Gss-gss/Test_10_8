# One-hot 加 BiLSTM 注意力分类器结果

本实验在 NVIDIA GeForce RTX 5050 Laptop GPU 上完成五折训练。输入为 31 × 21 的 One-hot 矩阵；分类器为 BiLSTM、LayerNorm、多头注意力、GELU、Dropout 0.5 和全连接残差连接。

## 结果

| 指标 | 五折平均值 | 样本标准差 |
|---|---:|---:|
| SN | 0.6000 | 0.5477 |
| ACC | 0.4999 | 0.0003 |
| SP | 0.4000 | 0.5477 |
| MCC | 0.0000 | 0.0000 |
| AUC | 0.5464 | 0.0248 |

该训练配置没有形成有效分类器：不同折在阈值 0.5 下分别塌缩为全负或全正预测，验证损失约为 0.693（近似随机二分类损失）。因此，该结果**不是性能提升**，而是“将论文训练参数直接迁移至 One-hot 输入”不可行的证据。

## 原因与下一步

论文报告的学习率 0.01、L2 正则 0.005、Dropout 0.5 是针对其经过 LightGBM 筛选的融合特征与原始训练流程设定的。将这些参数直接迁移到 31 × 21 One-hot 序列输入，需要重新调参。

推荐下一步是在训练折内选择学习率、权重衰减、hidden size 和 dropout，例如先搜索：

- 学习率：0.0003、0.001、0.003；
- L2 权重衰减：0、0.00001、0.0001、0.001；
- Dropout：0.1、0.3、0.5；
- hidden size：32、64、128。

调参必须只使用训练折内部验证集，外层测试折仍仅用于最终评估，避免性能估计偏高。
