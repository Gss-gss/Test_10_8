# 调参 One-hot BiLSTM 注意力模型结果

本实验使用 GPU 运行外层分层五折交叉验证。每个外层训练折另划分 15% 的内部验证集，仅以该验证集选择学习率、L2 权重衰减、Dropout、隐藏层大小和训练 epoch；外层测试折始终隔离。

| 指标 | 五折平均值 | 样本标准差 |
|---|---:|---:|
| SN | 0.6882 | 0.1527 |
| ACC | 0.5857 | 0.0081 |
| SP | 0.4830 | 0.1583 |
| MCC | 0.1833 | 0.0160 |
| AUC | 0.6340 | 0.0037 |

## 与既有实验的比较

| 方法 | ACC | MCC | AUC |
|---|---:|---:|---:|
| One-hot + 逻辑回归 | 0.5601 | 0.1201 | 未计算 |
| 五特征融合 + LightGBM 选择 + 逻辑回归 | 0.5535 | 0.1070 | 0.5783 |
| One-hot + 直接迁移论文训练参数的 BiLSTM 注意力模型 | 0.4999 | 0.0000 | 0.5464 |
| **One-hot + 训练折内调参的 BiLSTM 注意力模型** | **0.5857** | **0.1833** | **0.6340** |

## 解释

内部验证集最常选中 B 或 D：较低学习率（0.001 或 0.0005）、较低 L2 权重衰减（0.001 或 0.00001）以及较低 Dropout（0.3 或 0.1）。与将论文的学习率 0.01、L2 0.005 和 Dropout 0.5 直接迁移相比，调参后的模型不再塌缩为全正或全负预测。

SN 的折间波动仍然较大，说明阈值 0.5 下正负类别的取舍不稳定。后续可在每个训练折的内部验证集上进一步选择分类阈值，或增加独立测试集以获得更稳定的泛化估计。
