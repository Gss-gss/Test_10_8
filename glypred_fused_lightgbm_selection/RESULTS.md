# 五特征融合加 LightGBM 选择结果

在每一折训练集中拟合 LightGBM，并保留 `split` 重要性大于 2 的特征。测试折不参与特征筛选。

| 指标 | 五折平均值 | 样本标准差 |
|---|---:|---:|
| SN | 0.5516 | 0.0147 |
| ACC | 0.5535 | 0.0142 |
| SP | 0.5553 | 0.0212 |
| MCC | 0.1070 | 0.0284 |
| AUC | 0.5783 | 0.0160 |

每折从 1,841 个特征中保留 435 至 464 个，平均为 454.8 个。五个 EBGW 特征组均被保留，AAC 与 PWAA 几乎全部保留；筛选主要压缩 KMER 和 DR 特征。

| 对比实验 | ACC | MCC |
|---|---:|---:|
| One-hot + 逻辑回归 | 0.5601 | 0.1201 |
| 五特征融合 + 逻辑回归 | 0.5479 | 0.0958 |
| 五特征融合 + LightGBM 选择 + 逻辑回归 | 0.5535 | 0.1070 |

结论：LightGBM 特征选择相对于未筛选的五特征融合提高了 MCC（0.0958 → 0.1070），但仍未超过当前 One-hot 逻辑回归基线（0.1201）。下一步应测试将 LightGBM 直接作为分类器，或使用论文的 BiLSTM 加多头注意力分类器。
